## 3. Link prediction

### Protocol

```
Run every model on the same splits and write reports/model_comparison.json.

    python -m ml_pipeline.graph.evaluate                 # full benchmark
    python -m ml_pipeline.graph.evaluate --quick         # smaller query sets (smoke test)

Protocol (identical for every model):
  T1  test jobs, known half -> rank all skills except the known ones; targets = hidden half
  T2  every ESCO occupation, known 80% -> rank the rest; targets = hidden 20%
  T3  2,000 pseudo-candidates -> rank the ~9.5K pool jobs; source job grade 2,
      same-occupation jobs grade 1. recall@10 here = source job in the top 10.
Metrics: recall@10, NDCG@10, MRR (rank among all items), each with a 95% bootstrap CI;
paired bootstrap differences against the best baseline; p50/p95 online latency; memory.
Stochastic models run with 3 seeds; the table reports the mean over seeds.

Each model's result is checkpointed to artifacts/graph/bench_*/ as soon as it finishes.
`--resume` reuses checkpoints newer than the graph data, so an interrupted run continues
from the model it stopped at; without it, checkpoints are cleared and everything is rerun.
```

Leakage checks (asserted before any model runs): hidden job-skill edges visible to models = 0, hidden occupation-skill edges visible = 0, near-duplicate groups spanning splits = 0, T3 sources all in the unseen pool = True. All model selection used 1,000 dev queries built from train jobs.

## 8. Limitations

- Naukri postings are formal-sector, English-language and urban-skewed; the informal economy is invisible here.
- About two weeks of postings: no trend or forecast is claimed.
- ESCO is European; many current tools (cloud platforms, frameworks) have no ESCO skill and stay as raw tags.
- Eligibility (covering a share of a posting's skills) is not hiring; no outcome data exists in this dataset.
- Salary is posted, not realised, and only disclosed on a non-random third of postings.
- The recruiter candidate pool is SYNTHETIC and labelled as such everywhere; it demonstrates ranking, not real-candidate quality.
- Supply is a state-level proxy (AISHE out-turn, PLFS youth unemployment), not field-level graduate counts.
- Gold linking metrics depend on the team's labels; until labelled, thresholds are provisional.
